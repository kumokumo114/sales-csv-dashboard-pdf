## Reproduce

```bash
python -m pip install -e ".[dev]"
python -m pytest -q
python -m ruff check .
node --check sales_dashboard/static/app.js
python -m pip wheel . --no-deps --wheel-dir dist
```

For browser tests, start `python -m sales_dashboard`, install the optional Playwright developer dependency as described in the README, and run `node scripts/browser-smoke.cjs`. Screenshots and downloaded test reports are written to ignored `test-results/`.
